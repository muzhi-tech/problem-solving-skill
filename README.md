# Problem Solving Skill · 江丕权解决问题策略

> A Claude / AI-agent skill that turns Jiang Piquan's *Strategies and Skills for Problem Solving* into an actionable decision map — grounded in the book's original ledger, not generic advice.

> 基于江丕权《解决问题的策略与技能》**行动台账**的 Claude / AI agent skill。它把书本的策略知识转成**可执行的行动地图**，而不是套用 MECE / SWOT / PDCA 这类通用方法论。

---

## ✨ 它和"直接问通用 AI"有什么不同

通用助手遇到「怎么解决」「卡住了」「没思路」时，往往给出**正确但泛泛**的模板（"先分析根因，再列方案……"）。本 skill 强制遵循两条**还原度铁律**：

1. **每条建议都必须能在台账里找到原书出处**——不发明方法论，只用书里的原始命名（`五步策略`、`脑风暴法`、`分类`、`知识结构`、`交流系统`、`解决交流问题的步骤`）。
2. **命中反模式时，先用作者原话警示，再给步骤**——不软化为通用鼓励。

## 📚 台账框架速查

### 六大框架

| 框架 | 一句话 | 适用场景 |
|---|---|---|
| **五步策略** | 弄清问题 → 探索思考 → 拟定计划 → 实现计划 → 回顾总结 | 怎么解决、怎么计划、怎么复盘 |
| **脑风暴法** | 延迟判断、强调数量、现场记录、引发物 | 发散创意、小组讨论、突破思维僵化 |
| **分类** | 同一标准、逐级分类、先明确目的 | 信息过载、资料杂乱、理头绪 |
| **知识结构** | 多要素、多序列、多层次、动态综合体 | 学新领域、建长期可调用知识 |
| **交流系统** | 交流者 / 对象 / 媒介 / 共享 四元素 | 写报告、演讲、PPT、说服 |
| **解决交流问题的步骤** | 确定问题 → 计划 → 初稿 → 完善 | 写不出、讲不清、汇报混乱 |

### 核心原则

- **逐级近似 / 逐步复杂 / 逐步精确**——不追求一次到位，从粗到细。
- **策略必要而非充分**——还要技能、知识、态度和判断。
- **探索思考**——不求答案，求联系与可能途径。
- **回顾总结**——做完不收，等于只种不收。
- **延迟判断**——生成阶段推迟评价，新思想才会出现。
- **确定问题的平衡**——在过分笼统与过分精确之间取平衡。

### 反模式（skill 会主动拦截并警示）

| 反模式 | 触发信号 |
|---|---|
| 刚刚触及想象的问题便动手解 | "我大概知道，直接给方案" |
| 误认为必须用数学来解决问题 | 只问公式 / 算法，却不界定问题 |
| 误认为只有一种正确方法 | 纠结唯一最优、否定备选 |
| 先在头脑里想完才动笔 | 一直想，不写、不画、不列 |
| 机械的步骤或程序 | 把策略当检查表僵化执行 |
| 过分强调限制条件 | 一开口就"不可能 / 没预算 / 没时间" |
| 脑风暴中批评想法 | 发散阶段说"不现实 / 没用 / 更好的是……" |

### 作者的三种"声音"

- **教练式**："平静下来。我们一个有组织的方法，一次前进一步。好，现在开始。"
- **反问复盘**："假如丢掉了这一步，岂不是只种不收吗？"
- **动员式**："时刻带着疑问的头脑去看！去听！去思考！"

## 🚀 安装与使用

### 安装到 Claude Code

```bash
git clone https://github.com/muzhi-tech/problem-solving-skill.git ~/.claude/skills/problem-solving-skill
```

> ⚠️ 目录名必须是 `problem-solving-skill`（与 `SKILL.md` 的 `name` 字段一致），否则 skill 无法被加载。

### 怎么触发

无需手动调用。Claude 会根据你的问题描述自动召回本 skill。例如：

- "上线出了事故，怎么复盘才有用？"
- "下周汇报讲不清楚，PPT 该怎么组织？"
- "我们开会想多出点子，怎么开效率高？"
- "资料太多脑子很乱，怎么理出头绪？"
- "这个需求我大概知道，直接给我方案就行。"

最后一句会触发**反模式拦截**——skill 会先警示「刚刚触及想象的问题便动手解」，再退回「弄清问题」。

### 典型响应形态

```markdown
**定位**　[原书框架名 + 一句为何适用]
**原书抓手**
- [台账中的精确表述]
**行动地图**
1. [立即动作]
2. [下一步]
3. [验证 / 复盘]
**警示**　[命中反模式时，套用作者原话]
```
